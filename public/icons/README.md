# PWA Icons

Este projeto usa SVGs escaláveis que funcionam em qualquer tamanho.

## Ícones Disponíveis
- **icon-source.svg** (512x512) - Ícone principal, usado para todos os tamanhos
- **icon-72x72.svg** (72x72) - Ícone para iPad/tamanhos menores
- **icon.svg** - Ícone geral do site

## Como funciona
O manifesto do PWA referencia diretamente os SVGs. Navegadores modernos
suportam SVG em qualquer tamanho sem necessidade de múltiplos PNGs.

## Splash Screens
iOS gera splash screens automaticamente a partir do ícone quando necessário.
Se precisar de splash customizado, crie um PNG com fundo #09090B e ícone centralizado.
